# ELM369 Termux Suite

Termux setup scripts and Python simulation/training modules for:
- **3D Liquid & Color Wheel (`gyro_liquid.py`)**: Gyroscopic wave interference and color lock/unlock controls.
- **Multi-Layer Qbit & Engine Matrix (`qbit_engines_termux.py`)**: State simulation across Qbits, Engines, Qbit Engines, Unreal Engines, and Qbit Unreal Engines.
- **Audio & AI Frequency Controller (`qbit_audio_termux.py`, `ai_audio_assistant.py`)**: Frequency, harmonic, and $360^\circ$ hue wheel tracking with lock/unlock support.
- **Project ELM369 Training Program (`elm369_training_program.py`)**: Episode and readiness tracking across AI, robots, drones, autonomous vehicles, and industrial/farm equipment.
- **Save & Reclaim Utility (`save_reclaim_point.sh`)**: Checkpoint archiving and restoration for Termux files and configurations.
